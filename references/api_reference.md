# Reference documentation

This skill intentionally has no fixed external API dependency.

Use this file as a lightweight note:

- Prefer project-local, version-pinned software and existing validated matrices.
- Record exact command lines, package versions, random seeds, input hashes, and output hashes.
- If using TreeCluster, PhyCLIP, Leiden/igraph, Infomap, SNF, Biopython, ETE, or DendroPy, follow the installed version's own documentation and record the exact version.
- Do not assume one package is mandatory; substitute an equivalent method when needed and document the substitution.
- Keep tree topology and primary pairwise evidence immutable unless the user explicitly authorizes recomputation.
